Device configuration for Redmi Note 15 5G (Kunzite)
===================================================

The Redmi Note 15 5G is a mid-range smartphone from Xiaomi's sub-brand REDMI.

The device was announced in December 2025.

## Device specifications

Basic   | Spec Sheet
-------:|:-------------------------
CPU     | Octa-core (4x2.4 GHz Cortex-A78 & 4x1.8 GHz Cortex-A55)
Chipset | Qualcomm SM6475-AB Snapdragon 6 Gen 3 (4 nm)
GPU     | Adreno 710
Memory  | 6/8/12 GB RAM
Shipped Android Version | 15
Storage | 128/256/512 GB (UFS 2.2)
Battery | Non-removable Si/C Li-Ion 5520 mAh
Display | 1080 x 2392 pixels, 6.77 inches (~388 ppi pixel density), AMOLED, 120Hz
Camera  | 108 MP wide camera (OIS), 8 MP ultra wide-angle camera, 20 MP front camera
